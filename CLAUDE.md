# Workflow

## Feature development

- Every new feature is developed in a worktree under `.claude/worktree`.
- When asked to build a new feature, the first step is **always** to create a `plan.md`.
  - `plan.md` must never be committed — it is a working document used to review the implementation approach in detail before any code is written.
- If a feature seems very complex, also think about easier ways to implement something similar. If you find a simpler alternative, tell me and provide suggestions **before** writing the plan.
- If anything about the requested feature is ambiguous, ask me questions before writing the plan.
